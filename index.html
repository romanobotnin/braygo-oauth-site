LSS Wiki CLI

A private, local-first assistant for organizing and searching an authorized user's knowledge base.

Google Workspace access

LSS Wiki CLI connects to Google Workspace only after the user explicitly grants access. It requests read-only access to Google Drive, Gmail, Sheets, and Docs so the user can retrieve information they are already authorized to view.

The application does not send corporate documents to public AI services automatically and does not modify Google Workspace content.
