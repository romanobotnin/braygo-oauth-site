Privacy Policy

Effective September 9, 2026

Overview

LSS Wiki CLI is a private, local-first tool used by an authorized user to search and organize their own knowledge base. This policy explains how the application handles information obtained through Google APIs.

Information accessed

After explicit OAuth consent, the application may read files and metadata from Google Drive, messages and metadata from Gmail, and content from Google Sheets and Google Docs. Access is read-only and is limited to the Google account selected by the user.

Purpose and use

Google user data is used only to complete the user's requested retrieval, analysis, or knowledge-base task. The application does not use Google user data for advertising, profiling, credit decisions, or training public AI models.

Storage and security

OAuth credentials are encrypted at rest on the user's device, with the encryption key stored in the operating system keychain. Retrieved content is processed locally unless the user separately and explicitly authorizes another destination. The application does not sell Google user data.

Sharing

Google user data is not shared with third parties except when required by law or when the user explicitly directs the application to send specific information to a specified service.

Retention and deletion

Transient query results are retained only as needed to complete the requested task. Knowledge-base records are retained locally under the user's control. The user can delete local records and revoke the application's Google access at any time from their Google Account security settings.

Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Material changes to this policy will be published on this page with a revised effective date.

Contact

Support requests can be sent to the developer contact address displayed on the Google OAuth consent screen.
